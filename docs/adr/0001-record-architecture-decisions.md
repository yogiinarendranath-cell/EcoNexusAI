# ADR-0001: Record Architecture Decisions

- Status: Accepted
- Date: 2026-09-15

## Context
We will make many architectural decisions. Without a record, future-us will not
remember the reasoning, and interviewers cannot see it either.

## Decision
Use ADRs in `docs/adr/` with this format: Title, Status, Context, Decision,
Consequences. Every non-trivial decision gets an ADR.

## Consequences
**Positive:** decisions traceable, portfolio asset.
**Negative:** small overhead per decision.
**Follow-ups:** ADR-0002 through ADR-0005 recorded now.
